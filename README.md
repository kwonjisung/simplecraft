# 심플크래프트

브라우저에서 바로 하는 미니 실시간 전략 게임입니다. 미네랄을 캐고, 건물을 올리고, 병력을 모아 상대 기지를 무너뜨리세요.

## 플레이

`index.html`을 브라우저로 열면 바로 시작됩니다. 설치나 빌드가 필요 없습니다.

## 특징

- 6종족: 철벽 연합, 붉은 군락, 성광 교단, 이끼 숲, 모래바람 유목민, 심연 공학
- 맵 3종: 격전지, 대평원(넓은 맵), 무한 광맥(미네랄 무한)
- 대전 방식: 1:1, 개인전(최대 6명), 1:다 연합전
- 난이도 3단계, 효과음, 종료 후 전체 플레이어 기록 비교

## 조작

- PC: 좌클릭 선택, 드래그 범위 선택, 우클릭 이동·공격·채광, 단축키 Q W E R / A / S / M
- 모바일: 탭으로 선택과 명령, 한 손가락 드래그로 시점 이동
